__用于获取NVIDIA历史驱动的工具程序__

> [!WARNING]
> __此项目系 [`NVIDIA_HDA`](https://github.com/FeiLingshu/NVIDIA_HDA) 的重置版本__
> - __自 `2026.4.9` 起，NVIDIA官网全面启用新的前端页面，旧项目已无法正常工作__
> - __由于 `Manifest-V3` 及 `CSP` 的安全限制，无法动态修改网络站点的JS代码__
> - __新版NVIDIA官网的后端代码中使用了无法在 `content` 世界中运行的代码，旧项目中使用的运行策略经测试已无法正常工作__

### __改进说明__

__较旧项目，本重置版本对功能进行了以下修改动__
- [x] __保留了强制检索 `Standard` 版本的功能__
   - __不建议使用此功能（可能会导致检索不到任何驱动），如有需要请将系统版本设置为 `win7` 再进行搜索__
- [ ] __移除了处于测试状态的 `Beta` 版本驱动的检索功能（目前依旧没搞明白实现方式）__
- [x] __添加了可配置的驱动类别筛选项，现允许仅搜索 `Game Ready` 驱动或 `Studio` 驱动__
- [x] __保留了可配置的 `version` 和 `release` 两个额外参数（前者用于搜索特定版本，后者用于搜索特定release系列）__
> - __由于请求过多查询数量可能造成数据包返回超时，可使用上述参数避免超时带来的负面影响__
> - __`version` 参数用于已知精确版本号时进行查询，若某版本号同时存在 `Game Ready` 和 `Studio` 版本，将根据用户配置的筛选条件进行查询__
> - __`release` 参数用于支持搜索一系列驱动程序，参数数值为整数，根据作者本人分析，参数应当符合可被 `5` 整除的特征，与驱动版本号的前半部分基本保持一致（例如 `version=999.99 -> release=995/990` `version=111.11 -> release=110`），目前尚不清楚NVIDIA对该参数的定义，但该参数可正常截取部分驱动程序列表（若使用某 `release` 参数未能找到特定的驱动版本，请根据现有搜索结果和查询目标之间的关系，以5为单位调整 `release` 参数）__

### __使用方式__

- __确认使用前检查已正确执行__
- __解压缩 `zip` 包体至某文件夹内 (不建议使用系统目录中的文件夹，可能存在权限问题)__
- __启动程序，并等待主程序连接成功 (若显示连接失败，大概率是网络问题)__
- __配置所需的查询参数__
- __点击按钮启动 `WebView2` 组件__
- __正常进行驱动搜索即可 (无需任何额外操作)__
  - ___首次加载可能存在一定延迟___
  - ___如 `NVIDIA` 页面长时间未返回查询结果，基本可以判定为连接 `NVIDIA` 服务器超时，请尝试减少查询数量___
- __重新设定查询参数需关闭当前 `WebView2` 组件窗口__
- __不要删除程序所在文件夹中的任何新生成的文件__
